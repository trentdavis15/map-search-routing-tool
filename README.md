# Map Search & Routing Tool

This project was developed for **CS 340: Software Design III** at the University of Wisconsin–La Crosse.  
It allows users to find the shortest route between U.S. cities using graph-based algorithms.

---

## Overview
The program models cities and connections as a weighted graph and determines the shortest route between two points.

### Key Features
- Built with **Java** using OOP principles  
- Implements **Dijkstra’s Algorithm** for shortest path calculation  
- Supports flexible map input and customizable route outputs  

---

## Technologies Used
- **Language:** Java  
- **Concepts:** Data Structures, Algorithms, Object-Oriented Programming  
- **Tools:** VS Code, JDK
